# Markdown Viewer

A browser-based Markdown editor and preview built with React, TypeScript, and Vite. It includes syntax highlighting, Mermaid diagrams, math rendering, search, recent files, and export tools.

## Run locally

```bash
git clone https://github.com/ipvesp/markdown-viewer.git
cd markdown-viewer
npm install
npm run dev
```

Use `npm run build` for a production build. Documents and preferences are stored in the browser.
